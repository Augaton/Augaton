- 🎮 I make **Garry's Mod** addons for SCP roleplay servers.
- 🧪 I write **EXILED** plugins for **SCP: Secret Laboratory**, mostly modern rewrites of community classics.
- 🕹️ I build small games in **C** and **C++**, FTL-likes above all.
